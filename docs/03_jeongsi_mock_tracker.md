# [모듈 3] 정시 모의고사 트래커 & 수능 로드맵

## 1. 개요
2028 통합형 수능 체계에 맞춰 고2~고3 전국연합학력평가 및 수능 모의평가 성적을 시계열로 누적 관리하고, 목표 대학의 정시 수능 환산점수 및 합격 예상선과의 격차(Gap)를 분석하는 모듈입니다.

---

## 2. 2028 통합형 수능 과목 체계

* **국어 영역**: 공통 (화작/언매 선택과목 없음)
* **수학 영역**: 공통 (대수, 미적분Ⅰ, 확률과통계 공통 출제 / 기하·미적분Ⅱ 선택 폐지)
* **영어 영역**: 절대평가 (1~9등급, 10점 단위 등급 컷)
* **한국사 영역**: 절대평가 (1~9등급)
* **탐구 영역**: **통합사회, 통합과학 공통 필수 응시** (문/이과 구분 없이 두 과목 모두 응시)

---

## 3. 세부 기능 요구사항

### 3.1 모의고사 성적 기록 대장
- **회차별 관리**:
  * 고2: 3월, 6월, 9월, 11월 전국연합학력평가
  * 고3: 3월, 5월, 6월(평가원), 7월, 9월(평가원), 10월, 11월(수능)
- **과목별 입력 항목**:
  * 원점수 (100점 만점 / 탐구·한국사 50점 만점)
  * 표준점수
  * 백분위 (0~100%)
  * 등급 (1~9등급)

### 3.2 성적 추이 시각화 (동기부여 그래프)
- **과목별 꺾은선 차트**:
  * 회차별 백분위 및 표준점수 변화 추이를 다각도로 시각화
  * "국어는 꾸준한 상승세 📈, 수학은 정체 구간 📊" 등 성적 트렌드 분석 태그 표시
- **목표선 오버레이**:
  * 차트 위에 목표 대학의 '합격자 평균 백분위'를 점선(Goal Line)으로 겹쳐 표시하여 시각적 자극 및 목표 의식 부여

### 3.3 대학별 정시 환산점수 계산 엔진
- 대학마다 다른 수능 반영비율 적용:
  $$\text{대학 환산총점} = (\text{국어 환산} \times W_{kor}) + (\text{수학 환산} \times W_{math}) + (\text{탐구 환산} \times W_{inq}) + \text{영어 가감점} + \text{한국사 가감점}$$
- **정시 Gap 분석 (액션 플랜 도출)**:
  * *"목표 OO대학교 컴퓨터공학과 정시 컷(환산 870점)까지 현재 35점 부족"*
  * *"부족 점수를 채우기 위한 최적의 시나리오: 수학 백분위 +4% (약 1문제) 또는 탐구 표준점수 +6점 달성"*
