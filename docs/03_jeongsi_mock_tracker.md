# [모듈 3] 정시 모의고사 트래커 & 수능 로드맵

## 1. 개요
2028 통합형 수능 체계에 맞춰 고2~고3 전국연합학력평가 및 수능 모의평가 성적을 시계열로 누적 관리하고, 목표 대학의 정시 수능 환산점수 및 합격 예상선과의 격차(Gap)를 분석하는 모듈입니다.

---

## 2. 2028 통합형 수능 과목 체계

* **국어 영역**: 공통 (화작/언매 선택과목 없음)
* **수학 영역**: 공통 (대수, 미적분Ⅰ, 확률과통계 공통 출제 / 기하·미적분Ⅱ 선택 폐지)
* **영어 영역**: 절대평가 (1~9등급, 10점 단위 등급 컷)
* **한국사 영역**: 절대평가 (1~9등급)
* **탐구 영역**: **통합사회, 통합과학 공통 필수 응시** (문/이과 구분 없이 두 과목 모두 응시)

---

## 3. 세부 기능 요구사항

### 3.1 모의고사 성적 기록 대장 (`MockExamTable.tsx`, `MockExamModal.tsx`)
- **회차별 관리**:
  * 고2: 3월, 6월, 9월, 11월 전국연합학력평가
  * 고1: 3월, 6월, 9월, 11월 전국연합학력평가
  * 고3: 3월, 5월, 6월(평가원), 7월, 9월(평가원), 10월, 11월(수능)
- **과목별 입력 항목 (2028 통합수능 6과목)**:
  * 국어(표준점수/백분위/등급), 수학(표준점수/백분위/등급)
  * 영어(원점수/등급), 한국사(원점수/등급)
  * 통합사회(표준점수/백분위/등급), 통합과학(표준점수/백분위/등급)
- 모의고사 추가/수정/삭제 모달 지원.

### 3.2 성적 추이 시계열 차트 (`MockExamChart.tsx`)
- **SVG 인터랙티브 꺾은선 차트**:
  * 영역별(국어, 수학, 탐구) 백분위 변화 궤적을 3차 베지어 곡선으로 렌더링.
  * 목표선(Goal Line, 85% 등급선) 점선 오버레이 및 호버 툴팁 지원.
  * 반응형 뷰포트 지원.

### 3.3 정시 목표 대학 실시간 Gap 분석기 (`JeongsiGapCard.tsx`)
- 인하대, 국립인천대, 중앙대 대학별 수능 영역별 반영 가중치 적용 백분위 계산:
  $$\text{환산 가중 백분위} = \frac{\sum (\text{영역별 백분위} \times \text{영역 가중치})}{\sum \text{총 가중치}}$$
- **정시 Gap 뱃지 & 액션 플랜**:
  * `[안정권 🟢]` (합격선 초과) / `[도전권 🟡]` (Gap -1~3%) / `[보완필요 🟠]` (Gap -3% 이상)
  * *"인천대 사범대 정시 70% 컷(80.3%) 대비 현재 백분위 +1.2%로 최초 합격 안정권!"*
  * *"수학 4점 1문제 추가 득점 시 인하대 공대 정시 70% 컷 진입 가능"*
