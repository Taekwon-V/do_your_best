# 🎓 2028 대입 전략 매니저 (College Admissions Strategy Web App)

> **대상**: 2028+ 대입 개편안 적용 대상자 **(첫째: 현재 고2 / 둘째: 현재 고1)** 및 학부모  
> **핵심 목표**: 내신 5등급제 및 통합형 수능 체제에 맞춘 다자녀 수시·정시 목표 관리, 역산 시뮬레이션, 구글 가족 전용 클라우드 동기화 대시보드 제공

---

## 1. 프로젝트 배경 및 두 자녀 상황 정의

첫째와 둘째 모두 **2028+ 대입 개편안(내신 5등급제 상대평가 10% + 문·이과 통합형 수능)**이 전면 적용되는 세대입니다:

| 자녀 구분 | 현재 학년 | 대입 연도 | 확정 성적 (실제) | 역산 시뮬레이션 대상 학기 (가상) |
| :--- | :--- | :--- | :--- | :--- |
| **첫째** | **고2** | 2028학년도 | **1-1, 1-2, 2-1 (3개 학기 완료)** | **2-2, 3-1 (남은 2학기 집중 역산 ⭐)** |
| **둘째** | **고1** | 2029학년도 | **1-1 (1개 학기 완료)** | **1-2, 2-1, 2-2, 3-1 (남은 4학기 장기 로드맵 ⭐)** |

## 3. 단계별 개발 로드맵 (Phased Roadmap)

2. **[Phase 2]** [`PHASES/PHASE2.md`](PHASES/PHASE2.md): 2028 5등급제 내신 계산 엔진 & **고2/고1 맞춤형 수시 역산 시뮬레이터 MVP**
3. **[Phase 3]** [`PHASES/PHASE3.md`](PHASES/PHASE3.md): 2028 통합형 수능 모의고사 트래커 & 시계열 차트 및 Gap 분석
4. **[Phase 4]** [`PHASES/PHASE4.md`](PHASES/PHASE4.md): 자녀별 목표 대학 포트폴리오 (수시 6장 + 정시 3군) & 동기부여 종합 대시보드
