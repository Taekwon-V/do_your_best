## 2. 세부 개발 완료 내용

### 2.1 2028 통합수능 성적 입력 대장 & 모달 (`src/components/mockTracker/MockExamTable.tsx`, `MockExamModal.tsx`)
- 시험 회차 관리 (고1/고2 3월/6월/9월/11월 ➔ 고3 모의평가/수능)
- 2028 통합수능 6개 과목 전용 입력 폼:
  * 국어(공통) : 표준점수, 백분위, 등급
  * 수학(공통) : 표준점수, 백분위, 등급
  * 영어(절대평가) : 원점수(100만점), 등급 (1~9)
  * 한국사(절대평가) : 원점수(50만점), 등급 (1~9)
  * 통합사회(공통) : 표준점수, 백분위, 등급
  * 통합과학(공통) : 표준점수, 백분위, 등급
- 인라인 성적 수정, 삭제, 로컬스토리지 자동 영속화.

### 2.2 시계열 성장 추이 꺾은선 인터랙티브 차트 (`src/components/mockTracker/MockExamChart.tsx`)
- 영역별 백분위(0~100%) 시계열 성장 궤적 SVG 렌더링.
- 과목별 필터 토글 칩: `[전체]` `[수학]` `[국어]` `[통합과학]` `[통합사회]`
- **목표선(Goal-Line) 골드 점선 오버레이**: 목표 대학(예: 인하대 수학교육 85% / 인천대 80.3%) 컷 라인 실시간 비교.
- 호버 인터랙션: 회차별 국/수/영/탐 성적 서머리 스트립 즉시 출력.

### 2.3 정시 목표 대학 백분위 점수차(Gap) 분석 엔진 (`src/components/mockTracker/JeongsiGapCard.tsx`)
- 인하대, 인천대, 중앙대 주요 학과 목표 선택 드롭다운 연동.
- 대학별 영역 가중치(예: 수학 40%, 탐구 30%, 국어 25% 등) 자동 반영 환산 백분위 산출.
- **실시간 Gap 및 우선순위 처방전**:
  * *"목표 격차: 4.7%p 점수 부족 ⚠️"*
  * *"점수 도약을 위한 우선순위: 수학 4점짜리 1문제 더 맞히면 백분위 +3~5%p 상승하여 합격선 즉시 도달"*
