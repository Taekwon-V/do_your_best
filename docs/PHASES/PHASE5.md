# 💎 Phase 5: 가족 실시간 클라우드 동기화, 상담용 1장 PDF 리포트 & PWA 모바일 최적화

## 1. 단계 목표
* 부모님과 자녀가 어떤 기기(PC, 스마트폰, 태블릿)에서든 지연 없이 동일한 데이터를 볼 수 있도록 **실시간 클라우드 동기화**를 완성합니다.
* 학교/학원 입시 상담 시 지참할 수 있는 **A4 1장 요약 인쇄/PDF 리포트** 및 **스마트폰 PWA 앱 설치**를 지원하여 실사용 완성도를 극대화합니다.

---

## 2. 세부 개발 내용

### 2.1 가족 간 실시간 데이터 동기화 & 백업 (Module 5, 6 연계)
- Cloud Firestore / DB 실시간 리스너 연결:
  * 부모님이 PC에서 목표를 바꾸면 자녀의 폰에 1초 이내 자동 반영
- **개인정보 백업/복원**:
  * 데이터 `JSON 내보내기 (Export)` 및 `JSON 불러오기 (Import)` 지원 (데이터 유실 완벽 방지)

### 2.2 가족 상담용 A4 1장 요약 리포트 (One-page Print / PDF)
- 학교 담임선생님 또는 학원 입시 컨설턴트 상담 시 즉시 활용 가능한 고품질 출력 레이아웃:
  * 기본 프로필 & D-Day
  * 수시 6장 지원 포트폴리오 요약표
  * 내신 추이 및 잔여 학기 역산 목표
  * 모의고사 성적 추이 및 정시 합격 가능선
  * 이번 분기 최우선 집중 공략 과목
- 브라우저 인쇄(`window.print()`) 최적화 CSS 및 PDF 다운로드 기능

### 2.3 PWA(Progressive Web App) & 모바일 최적화
- PWA 매니페스트(`manifest.json`) 및 서비스 워커 설정:
  * 아이폰(Safari) "홈 화면에 추가", 갤럭시(Chrome) "앱 설치" 지원
  * 전용 앱 아이콘 및 스플래시 스크린 제공
- 터치 제스처 최적화 및 모바일 반응형 최종 폴리싱

---

## 3. 완료 검증 기준 (Definition of Done)
1. ✅ PC에서 성적 수정 시 스마트폰 화면이 새로고침 없이 실시간으로 업데이트됨.
2. ✅ JSON 파일로 백업 후 초기화 ➔ 복원 시 100% 정상 복구됨.
3. ✅ A4 인쇄 미리보기 시 페이지 넘어감 없이 정확히 깔끔한 1장으로 포맷팅됨.
4. ✅ 스마트폰 홈 화면에 앱 아이콘이 생성되고 전체 화면 모드로 매끄럽게 구동됨.
