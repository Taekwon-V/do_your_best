## 2. 세부 개발 완료 내용

- **2-2-2 전략 슬롯 시스템**: 소신 2장(Reach) / 적정 2장(Target) / 안정 2장(Safe).

- **수능최저학력기준 실시간 진단기**: 최신 모의고사 성적 기반 `[최저 충족 ✅]`, `[최저 위험 ⚠️]`, `[최저 미달 ❌]` 자동 판별.
- 인하대, 인천대, 중앙대 실측 5등급제 입결 프리셋 자동 채우기 및 사용자 직접 입력/수정/삭제.

- 최근 모의고사 환산 백분위 대비 실시간 Gap 뱃지 연동 (`+4.7%p 부족 ⚠️` / `안정권 ✅`).

### 2.3 6대 핵심 역량 밸런스 레이더 차트 (`src/components/portfolio/RadarBalanceChart.tsx`)
- 국어(수능), 수학(수능), 영어(수능), 탐구(수능), 전교과(내신), 주요과목(내신) 6축 SVG 방사형 레이더.
- 학생의 강점 영역(수학)과 보완 필요 영역(탐구/영어) 시각화.
