# 🧭 Phase 4: 목표 대학 포트폴리오 (수시 6장 + 정시 3군) & 동기부여 종합 대시보드

## 1. 단계 목표
* 분리되어 있던 수시(내신)와 정시(모의고사) 데이터를 결합하여 **입시 전황을 한눈에 조망하는 마스터 대시보드**를 완성합니다.
* 수험생(자녀)에게 목표 의식과 학습 동기부여를 제공하는 시각적 위젯들을 구축합니다.

---

## 2. 세부 개발 내용

### 2.1 수시 6장 + 정시 3군 포트폴리오 뷰 (Module 1 연계)
- **수시 6장 카드 그리드**:
  * 안정(Safe 2장) / 적정(Target 2장) / 소신(Reach 2장) 카드 슬롯
  * 각 카드별 목표 내신 컷, 수능최저 조건, 실시간 합격 확률 배지([안정 🟢 / 적정 🟡 / 소신 🟠 / 상향 🔴])
- **정시 3개 군(가/나/다군) 목표 배치 뷰**:
  * 군별 목표 학과 및 현재 모의고사 기준 환산 점수 차이 표시

### 2.2 동기부여 위젯 & D-Day 캘린더 (Module 4 연계)
- **D-Day 카운트다운**:
  * 다음 지필평가(중간/기말고사) D-Day
  * 다음 전국연합학력평가 D-Day
  * 2028 수능 시험일 D-Day
- **'만약에(What-If)' 전략 카드**:
  * 💡 *"이번 기말고사에서 수학 1등급 달성 시 ➔ 연세대 교과전형 '소신'에서 '적정'으로 승격!"*
  * 🎯 *"통합사회 백분위 5% 상향 시 ➔ 수시 6개 대학 수능최저 100% 충족!"*

### 2.3 6대 핵심 영역 밸런스 레이더 차트
- 국어, 수학, 영어, 통합사회, 통합과학, 내신 6개 축의 방사형(Radar) 차트
- 내신 vs 수능 불균형, 과목별 취약점 직관적 시각화

---

## 3. 완료 검증 기준 (Definition of Done)
1. ✅ 수시 6장 / 정시 3군 목표 카드를 자유롭게 추가/수정/삭제 가능.
2. ✅ 내신 또는 모의고사 성적이 변경될 때 포트폴리오 합격 뱃지가 실시간 재계산.
3. ✅ D-Day 및 What-If 카드가 학생의 현재 데이터에 맞게 지능적으로 생성됨.
