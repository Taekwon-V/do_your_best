# 🚀 Phase 1: 프로젝트 기반 설정, 구글 가족 인증 및 다자녀(고2, 고1) 프로필 뼈대 구축 [완료 ✅]

## 1. 단계 목표
* 민감한 두 자녀의 성적 데이터 보호를 위해 **온 가족(부모님, 고2 첫째, 고1 둘째) 전용 구글 로그인(화이트리스트)**을 구축합니다.
* 상단에서 **[첫째(고2) ↔ 둘째(고1)]를 원클릭으로 전환할 수 있는 반응형 쉘(Shell)**과 상시 접근 가능한 **웹 배포 환경(URL)**을 확보합니다.

---

## 2. 세부 구현 완료 내용

### 2.1 프론트엔드 프로젝트 뼈대 및 디자인 시스템
- **스택**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **디자인 테마**: **Happy Hues #17 큐레이션 팔레트** 전면 적용
  * 배경: 웜 크림 (`#fef6e4`)
  * 텍스트: 딥 미드나잇 네이비 (`#001858`, `#172c66`)
  * 포인트: 코랄 로즈 (`#f582ae`) & 파스텔 스카이 (`#8bd3dd`)
  * 컨테이너: 웜 피치 (`#f3d2c1`)
- **다자녀 캡슐 스위처 (`ChildProfileSwitcher`)**:
  * `[ 고2 첫째 (2028 대입) ]` ↔ `[ 고1 둘째 (2029 대입) ]` 원클릭 탭 전환
  * 모바일 2분할 터치 최적화 레이아웃 적용

### 2.2 구글 로그인 & 온 가족 화이트리스트 접근 제어 (Firebase Auth)
- **Firebase Google OAuth 연동**:
  * 프로젝트 ID: `do-your-best-fd8d3`
  * `signInWithPopup(auth, googleProvider)`를 통한 실제 구글 계정 원클릭 로그인
- **화이트리스트 보안 게이트 (`FamilyAccessGate`)**:
  * 등록된 가족 이메일만 대시보드 접근 허용
  * 비인가 외부인 계정 접근 시 즉시 차단 화면 표시 (임시 우회 테스트 버튼 완전 제거)

### 2.3 모바일 환경 & 카카오톡 인앱 브라우저 탈출 핸들러
- **카카오톡 탈출 (`InAppBrowserHandler`)**:
  * 카카오톡 인앱 웹뷰 감지 시 `kakaotalk://web/openExternal` 호출로 스마트폰 기본 브라우저(크롬/사파리) 자동 전환
  * 구글 로그인 차단(`403 disallowed_useragent`) 방지
- **모바일 반응형 최적화**:
  * 상단 네비게이션 2단 분할 (1단: 로고/계정, 2단: 자녀 스위처)
  * D-Day 카운트다운 칩 3분할 그리드 배치

### 2.4 실시간 웹 배포 (CI/CD 파이프라인)

- **Vercel 라이브 배포 주소**: [`https://do-your-best.vercel.app`](https://do-your-best.vercel.app)
