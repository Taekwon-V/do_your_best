# 🚀 Phase 1: 프로젝트 기반 설정, 구글 가족 인증 및 다자녀(고2, 고1) 프로필 뼈대 구축

## 1. 단계 목표
* 민감한 두 자녀의 성적 데이터 보호를 위해 **온 가족(부모님, 고2 첫째, 고1 둘째) 전용 구글 로그인(화이트리스트)**을 구축합니다.
* 상단에서 **[첫째(고2) ↔ 둘째(고1)]를 원클릭으로 전환할 수 있는 반응형 쉘(Shell)**과 상시 접근 가능한 **웹 배포 환경(URL)**을 확보합니다.

---

## 2. 세부 개발 내용

### 2.1 프론트엔드 프로젝트 뼈대 및 다자녀 스위처 UI
- Next.js (App Router) + TypeScript + Tailwind CSS 환경 구성
- **상단 프로필 스위처 컴포넌트 (`ChildProfileSwitcher`)**:
  * `[첫째 (고2)]` / `[둘째 (고1)]` 탭 전환 시 전역 `activeChildId` 변경
- 모던 다크/라이트 모드 테마 및 반응형 네비게이션 바

### 2.2 구글 로그인 & 온 가족 화이트리스트 접근 제어 (Module 6 연계)
- Google OAuth 인증 연동
- **가족 이메일 화이트리스트 필터링**:
  * 환경변수 `ALLOWED_FAMILY_EMAILS=parent1@gmail.com,parent2@gmail.com,child1@gmail.com,child2@gmail.com`
- **접근 분기**:
  * **[인가된 가족]**: 메인 대시보드 진입 (두 자녀 데이터 자유 전환)
  * **[비인가 외부인]**: 접근 거부 안내 페이지("등록된 가족 전용 서비스입니다.") 표시 및 차단

### 2.3 초기 데이터 스토어 (고2, 고1 초기 프로필 탑재)
- 초기 실행 시 고2(첫째), 고1(둘째) 기본 프로필 자동 생성:
  * 첫째: 고2 / 2028 대입 / 완료 학기 `['1-1', '1-2', '2-1']`
  * 둘째: 고1 / 2029 대입 / 완료 학기 `['1-1']`

### 2.4 클라우드 웹 배포 (CI/CD 파이프라인)
- Vercel 또는 Firebase Hosting을 통해 상시 접속 가능한 HTTPS 도메인 배포
- 부모님 PC 및 자녀 스마트폰 접속 테스트

---

## 3. 완료 검증 기준 (Definition of Done)
1. ✅ 미등록 구글 계정으로 로그인 시 즉시 접근 차단되는지 확인.
2. ✅ 등록된 가족 계정 로그인 시 상단에 `[첫째 (고2)] / [둘째 (고1)]` 스위처가 정상 노출되는지 확인.
3. ✅ 스위처를 눌렀을 때 자녀 프로필 전환이 렉 없이 즉각 반응하는지 확인.
4. ✅ 스마트폰 브라우저에서 배포된 URL로 접속하여 로그인 및 UI가 정상 동작하는지 확인.
