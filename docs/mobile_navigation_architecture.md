# 📱 모바일 중심 5대 탭 분리형 네비게이션 아키텍처 (Mobile 5-Tab Navigation Architecture)

> **핵심 설계 철학**: **"한 화면 = 한 개의 핵심 기능 집중 (Single-Purpose Focused Screen)"**  
> 단일 페이지의 끝없는 수직 스크롤(Infinite Scroll) 피로도를 제거하고, 모바일 스마트폰에서 엄지손가락으로 0.1초 만에 원하는 기능으로 전환할 수 있는 5대 메인 탭 구조를 정의합니다.

---

## 1. 5대 메인 탭 구조 개요

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  [로고] 2028 대입전략 매니저       [ 고2 첫째 (2028) ↔ 고1 둘째 (2029) ]       [내 계정]  │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  🏠 종합 홈   |   🎯 수시 내신&역산   |   📈 정시 모의고사   |   🎓 목표 대학   |   📑 입결&리포트  │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 2. 모바일 UI / UX 최적화 가이드라인

### 2.1 하단 고정 탭 바 (Mobile Bottom Navigation Bar)
* 스마트폰 하단에 항상 고정(Fixed Bottom)되어 엄지손가락으로 원터치 전환.
* 활성화된 탭은 `Deep Midnight Navy (#001858)` 또는 `Coral Rose (#f582ae)` 아이콘 및 굵은 폰트로 하이라이트.

### 2.2 상단 다자녀 스위처와의 연동
* 상단 `[고2 첫째]` ↔ `[고1 둘째]` 캡슐을 전환하더라도 **현재 머물러 있는 탭 화면(예: 수시 내신이면 수시 내신)이 유지되며 해당 자녀의 데이터로만 즉각 전환**됨.

### 2.3 스크롤 제로(One-Screen) 원칙
* 각 탭 화면은 모바일 뷰포트 기준 **1~1.5화면 이내로 간결하게 종결**되어 불필요한 긴 스크롤을 원천 방지함.
