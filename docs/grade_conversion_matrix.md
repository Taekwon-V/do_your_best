# 2028 5등급제 ↔ 9등급제 수시 단위수 가중 마스터 환산표 & 백분위 매트릭스

> **목적**: 2028학년도 대입 개편안(내신 5등급제 상대평가)과 과거 9등급제 입시 결과를 1:1로 정밀하게 상호 매핑하고, 수시 내신 관리 및 목표 등급 역산(Goal-Seek) 시뮬레이터의 기초 데이터 엔진으로 활용합니다.
> **표준 모델**: 일반고 5개 학기(고1-1 ~ 고3-1) 수시 반영 **총 124이수단위 (국·수·영 4단위, 탐구 3~4단위, 기타 2단위)** 가중평균 적용 (100만 명 몬테카를로 시뮬레이션 산출).

* **사회 / 한국사 / 과학**: 매 학기 3~4단위 × 5개 학기 ➔ **총 50단위 (40.3%)**
* **제2외국어 / 한문 / 기술가정**: 매 학기 2단위 × 5개 학기 ➔ **총 14단위 (11.3%)**

## 3. 핵심 입시 메커니즘 & 실전 적용 수칙

### 3.1 단위수 레버리지 (국·수·영 4단위의 중요성)
* 국어, 수학, 영어(각 4단위)는 2단위짜리 제2외국어/교양 과목보다 **내신 반영 가중치가 정확히 2배** 높습니다.
* 주요 4단위 과목에서 1등급을 확보하면, 비주요 과목에서 2~3등급을 받더라도 가중평균이 크게 방어됩니다.

### 3.2 수시 2대 전형별 합격 가이드
1. **학생부교과전형 (1.0 ~ 1.5등급 구간)**:
   * 1등급(상위 10%) 과밀화로 인해 내신 변별력이 축소되므로, **수능최저학력기준(2개 합 5~6, 3개 합 6) 충족 여부가 실질 합격을 지배**합니다.
2. **학생부종합전형 (1.5 ~ 2.2등급 구간)**:
   * 1단계 서류(3~4배수) 통과 후 **2단계 면접(30%) 및 전공 심화 세특으로 내신 0.3~0.5등급을 뒤집는 역전 합격의 핵심 구간**입니다.

## 4. 시뮬레이터(Goal-Seek Engine) 연동 규칙

* **자녀별 남은 학기 단위수 배분**:
  * **첫째(고2)**: 남은 2개 학기(2-2, 3-1) **총 52단위** 역산 시뮬레이션 적용.
  * **둘째(고1)**: 남은 4개 학기(1-2, 2-1, 2-2, 3-1) **총 104단위** 역산 시뮬레이션 적용.
* **목표 대학 갭 진단**:
  * 목표 학과의 70% Cut(5등급제 가중치 환산 기준)과 학생의 예상 누적 GPA를 실시간 비교하여 `[안정 / 적정 / 소신 / 도전]` 판정을 자동 산출합니다.
