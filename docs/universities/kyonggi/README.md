## 2. 전형별 핵심 요약

### [수시 전형]
1. **교과성적우수자전형 (학생부교과 100%)**:
   - **수능최저**: 국·수·영·탐(1) 중 **2개 영역 등급 합 7등급 이내** (한국사 필수)
   - **2028 5등급제 환산 70% Cut**: **2.20 ~ 2.50등급** (공공안전 2.10등급 / AI컴공 2.25등급 / 전자 2.28등급)
2. **학교장추천전형 (학생부교과 100%)**:
   - **수능최저 없음!** (고교별 인원 제한 완화)
   - **2028 5등급제 환산 70% Cut**: **2.25 ~ 2.55등급**
3. **KGU학생부종합전형 (1단계 서류 100%(3배수) + 2단계 서류 70% + 면접 30%)**:
   - **수능최저 없음!**
   - **2028 5등급제 환산 70% Cut**: **2.40 ~ 2.80등급** (일반고 2.3~2.5등급, 특목/자사고 포함 시 3.0등급대)
4. **SW우수자전형 (학생부종합 - SW컴퓨터계열)**:
   - **수능최저 없음!** 1단계 서류 100% + 2단계 면접 30%
   - **2028 5등급제 환산 70% Cut**: **2.45 ~ 2.65등급**

  - **[다군]**: AI컴퓨터공학부, 경영학부, 경제학부, 산업경영공학과, 전자공학부, 기계시스템공학, 바이오융합학부, 공공안전학부, 미디어영상학과, 관광개발경영 등 학과별 전원 다군 선발!

## 3. 우리 자녀 맞춤 지원 전략
- **현재 내신 2.41등급 기준**:
  - 경기대학교 **AI컴퓨터공학부 / 전자공학부 / 경영학부** 교과성적우수자전형(2합 7 최저 충족 시) 및 KGU종합/SW우수자전형에서 **'적정 및 합격 유력권(Target/Safe)'**으로 매우 이상적인 수시 6장 포트폴리오 카드!
- **정시 모의고사 백분위 70~90% 기준**:
  - 정시 다군 지원 시 경기대학교 IT/공과대학/경영학부가 **안정 지원 카드(Green Safe)**로 확고하게 기능.
