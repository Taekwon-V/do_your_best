## 🌟 인천대학교 핵심 입시 포인트 요약

### 1. 수시 핵심 전략
1. **학생부교과(교과성적우수자 - 456명)**:
   * **교과 100%** 일괄선발 (수능최저 적용)
   * **수능최저학력기준**:
     * **일반(인문/자연)**: 국, 수, 영, 사/과(1) 중 **2개 영역 등급 합 7 이내**
     * **동북아국제통상전공**: **2개 영역 등급 합 6 이내**
2. **학생부교과(지역균형 - 293명)**:
   * **교과 100%** 일괄선발 (고교장 추천, 인원 제한 없음)
   * **수능최저학력기준 없음 (미적용!)** ➔ 내신 관리가 우수한 학생의 핵심 안정/적정 카드
3. **학생부종합(자기추천 - 694명)**:
   * **1단계(3배수)**: 서류종합평가 100% ➔ **2단계**: 1단계 70% + 면접 30%
   * **수능최저학력기준 없음**
   * 사범대학 및 스포츠의학부는 1단계 4배수 선발
4. **교과 반영 방식의 독특성 (이수단위 가산점)**:
   * 교과 환산점수 + **이수단위 가산점 `[∑(반영교과 이수단위) × 0.05]`** (자유전공은 `× 0.2`) 부여로 충실한 이수자 우대!

### 2. 정시 핵심 전략
1. **모집군 분할 선발**:
   * **가군** (412명): 기계공학, 전기공학, 컴퓨터공학부(컴공/AI), 경영학부, 경제학과, 자유전공학부 등
   * **나군** (67명): 인공지능시스템공학과, 도시건축학부, 해양학과 등
   * **다군** (295명): 전자공학부(전자/반도체), 인공지능정보통신공학부, 신소재공학, 데이터과학과 등
2. **수능 반영 방식 (백분위 활용)**:
   * **자연계열**: 국어 25% / **수학 35%** / **탐구(2) 30%** / 영어 10% *(과탐 지정 폐지)*
   * **인문계열**: **국어 35%** / **수학 30%** / 탐구(2) 25% / 영어 10%
3. **영어 등급별 환산점수**:
   * 1등급 100점, 2등급 98점, 3등급 95점, 4등급 80점 (1~3등급 간 감점 폭이 2~3점으로 매우 작음)
