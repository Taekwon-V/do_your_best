   * 2학년 진입 시 계열, 학점 성적, 정원에 관계없이 희망 학과(전공) 100% 자율 선택 보장 (사범대, 예체능, 동북아스마트물류/IBE 제외)
4. **동북아국제통상전공 파격 특전**:
   * 수시 최초합격자 입학 학기 등록금 전액 지원, 해외대학 유학 기회, 기숙사 우선 배정
