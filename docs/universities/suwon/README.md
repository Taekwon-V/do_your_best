# 수원대학교 (University of Suwon) 2027/2028 대입 전략 가이드

## 1. 대학 개요
- **위치**: 경기도 화성시 봉담읍 와우안길 17
- **특징**: 경기 서남부권 주요 거점 4년제 사립대학교
- **주요 전략 계열**:
  - **지능형SW융합대학**: 컴퓨터공학부, AI데이터과학부, 지능형보안학부
  - **혁신공과대학**: 전기전자공학부, 반도체공학과, 기계공학부, 화학공학·신소재공학부, 바이오공학과, 건설환경에너지공학부, 건축도시부동산학부
  - **경영공학대학 / 인문사회융합대학 / 자유전공학부**
  - **라이프케어사이언스대학**: 간호학과, 식품영양학과, 의류학과, 아동가족복지학과

## 2. 2027/2028 전형별 핵심 요약

### [수시 전형]
1. **교과우수전형 (학생부 교과 100%)**:
   - **수능최저**: 국·수·영·탐(1) 중 **2개 영역 합 7등급 이내** (간호학과: 2개 영역 합 6등급 이내)
   - **학생부 반영**: 성적 우수 교과 순으로 30%, 30%, 25%, 15% 반영 (자연: 국/수/영/과, 인문: 국/수/영/사)
   - **2028 5등급제 환산 70% Cut**: 2.30 ~ 2.65등급 (간호: 1.85등급)
2. **면접위주교과전형 (1단계 학생부 100%(5배수) + 2단계 학생부 60% + 면접 40%)**:
   - **수능최저 없음 (수능 이전 면접고사 실시)**
   - **2028 5등급제 환산 70% Cut**: 2.40 ~ 2.80등급
3. **고교추천전형 (학생부 교과 60% + 면접 40%)**:
   - **수능최저**: 국·수·영·탐(1) 중 **1개 영역 4등급 이내** (수능 이후 면접고사 실시)
   - **2028 5등급제 환산 70% Cut**: 2.60 ~ 3.10등급
4. **교과논술전형 (논술 80% + 학생부 20%)**:
   - **수능최저 없음 (수능 이후 논술고사 실시)**

### [정시 전형]
- **모집군**: **[나군]** 전원 선발 (일반학과/자연/인문/자유전공 모두 나군)
- **수능 일반전형 1 (수능 100%)**:
  - **자연계열**: 수학 30% 필수 + 상위 3개 영역(30%, 25%, 15%) 순 반영
  - **2028 통합수능 가중치 모델**: 수학 35%, 국어 25%, 탐구 25%, 영어 15%
  - **70% Cut 백분위**: 75.0% ~ 78.0% (간호: 83.5%)
- **수능 일반전형 2 (수능 100%)**:
  - 상위 3개 영역(45%, 35%, 20%) 반영

## 3. 우리 자녀 맞춤 지원 전략
- **현재 내신 2.41등급 기준**:
  - 수원대학교 **컴퓨터공학부 / 전기전자공학부 / AI데이터과학부** 교과우수전형 및 면접위주전형에서 **확실한 '안정/적정 합격권(Green Safe)'**으로 활용 가능.
- **정시 모의고사 환산 70~90% 기준**:
  - 정시 나군 지원 시 수원대학교 IT/공과대학 전 학과가 **안정 지원 카드**로 기능.
