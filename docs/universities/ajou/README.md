## 2. 전형별 핵심 요약

### [수시 전형]
1. **고교추천전형 (학생부교과 100%)**:
   - **수능최저**: 국·수·영·탐(1) 중 **2개 영역 등급 합 5등급 이내** (의학: 3개 1등급 / 약학: 3개 합 5)
   - **2028 5등급제 환산 70% Cut**: **1.45 ~ 1.75등급** (SW 1.65등급 / 전자 1.50등급 / 반도체 1.52등급)
2. **ACE전형 (학생부종합 - 대표 학종)**:
   - 1단계: 서류 100%(3배수) + 2단계: 서류 70% + 면접 30%
   - **수능최저 없음!** (의예/약학 제외)
   - **2028 5등급제 환산 70% Cut**: **1.60 ~ 2.10등급**
3. **첨단융합인재전형 (학생부종합 - 첨단IT/반도체/바이오/모빌리티)**:
   - **서류 100% 선발 (면접 없음 / 수능최저 없음!)**
   - **2028 5등급제 환산 70% Cut**: **1.65 ~ 2.00등급**
4. **논술우수자전형 (논술 80% + 교과 20%)**:
   - 수능최저 없음 (의예/약학 제외)

### [정시 전형]
- **모집군 분할**:
  - **[가군]**: 의학과, 간호학과
  - **[다군]**: 소프트웨어학과, 전자공학과, 반도체, 미래모빌리티, 사이버보안, 기계, 화공, 신소재, 경영, 금융공학, 바이오 등 **대부분의 주요 학과가 다군 핵심 모집!**
- **수능 영역별 반영비율**:
  - **자연계열**: 수학 35%, 탐구 30%, 국어 20%, 영어 15% (수학+탐구 65% 압도적 비중!)
  - **인문계열**: 국어 35%, 수학 25%, 탐구 25%, 영어 15% (경영/금융공학은 수학 35%)
- **70% Cut 백분위**: **85.0% ~ 90.5%** (사이버보안 90.3% / 신소재 90.5% / 반도체 89.5% / 간호 86.8% / SW 86.5% / 전자 86.2%)

- **현재 내신 2.41등급 기준**:
  - 아주대학교 공과대학 및 SW융합대학은 2028 5등급제 1.5~1.8등급선으로 **수시 6장 중 '소신/도전(Reach) 상향 카드'**로 포트폴리오 최상단에 배치하기에 완벽한 명문대입니다.
