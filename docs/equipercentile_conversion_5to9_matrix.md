> **이론적 근거**: 
> 5등급제와 9등급제는 모두 동일한 학생 집단의 정규분포 잠재 학업역량($\\theta \\sim N(0, 1)$)을 기반으로 평가됩니다.

## 1. 변환 수학 공식 (정규분포 표준점수 $Z$ 기반)

$$Z = \\frac{\\text{GPA}_5 - 3.00}{0.952} = \\frac{\\text{GPA}_9 - 5.00}{1.686}$$

* **5등급제 $\\rightarrow$ 9등급제 변환식**:
  $$\\text{GPA}_9 = 5.00 + 1.771 \\times (\\text{GPA}_5 - 3.00)$$
* **9등급제 $\\rightarrow$ 5등급제 변환식**:
  $$\\text{GPA}_5 = 3.00 + 0.565 \\times (\\text{GPA}_9 - 5.00)$$
