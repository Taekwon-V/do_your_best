# [모듈 1] 목표 대학 & 학과 설정 (Target Setup)

## 1. 개요
수험생(자녀)이 목표로 하는 대학 및 학과를 설정하고, 수시(6개 카드)와 정시(3개 군)별 지원 전략 포트폴리오를 구성하는 모듈입니다.

---

## 2. 세부 기능 요구사항

### 2.1 수시 6장 포트폴리오 관리
- **카드 배분 체계**:
  * 안정(Safe): 합격 확률이 매우 높은 대학 (예: 2개)
  * 적정(Target): 현재 성적과 합격선이 일치하는 대학 (예: 2개)
  * 소신/상향(Reach): 도전 목표 대학 (예: 2개)
- **전형 유형 선택**:
  * 학생부교과 전형 (내신 정량 + 수능최저 중심)
  * 학생부종합 전형 (내신 + 세특 정성평가)
  * 논술 전형 (논술 점수 + 수능최저)

### 2.2 정시 3개 군(가/나/다군) 목표 관리
- **군별 1지망/2지망 설정**:
  * 가군: 1개 대학/학과 선택
  * 나군: 1개 대학/학과 선택
  * 다군: 1개 대학/학과 선택

### 2.3 대학/학과별 전형 메타데이터 매핑
사용자가 대학 및 학과를 검색하거나 직접 입력할 때 다음 정보가 매핑되어야 합니다:
1. **내신 반영 방식 (수시)**:
   * 반영 교과목 (예: 전교과 / 국·수·영·과 / 국·수·영·사 등)
   * 학년별 반영 비율 (예: 1학년 20%, 2학년 40%, 3학년 40% 또는 전학년 100% 동일)
   * 전년도/예상 5등급제 환산 합격 컷 (상위 70% 컷, 평균 컷)
2. **수능최저학력기준**:
   * 등급 합 기준 (예: "국, 수, 영, 탐(1) 중 3개 영역 등급 합 7 이내")
   * 필수 포함 과목 여부 (예: "수학 포함 2개 합 5")
3. **정시 수능 영역별 반영 비율**:
   * 국어, 수학, 영어, 탐구(사/과), 한국사 반영 비중 (예: 국 30%, 수 40%, 탐 20%, 영 10%)

## 3. UI/UX 화면 요구사항
- **대학 검색 & 빠른 추가 UI**: 자동완성 검색 및 계열별(인문, 자연, 공학, 의약학 등) 필터
- **포트폴리오 카드 그리드 뷰**: 6장의 수시 카드와 3장의 정시 카드를 직관적인 카드 형태로 한눈에 조망
- **합격 확률 배지 표시**: 현재 성적 대비 목표 컷과의 거리에 따라 [안정 🟢 / 적정 🟡 / 소신 🟠 / 상향 🔴] 뱃지 실시간 갱신
