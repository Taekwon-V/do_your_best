# [모듈 1] 목표 대학 & 학과 설정 (Target Setup)

## 1. 개요
수험생(자녀)이 목표로 하는 대학 및 학과를 설정하고, 수시(6개 카드)와 정시(3개 군)별 지원 전략 포트폴리오를 구성하는 모듈입니다.

---

## 2. 세부 기능 요구사항

### 2.1 수시 6장 포트폴리오 관리
- **카드 배분 체계**:
  * 안정(Safe): 합격 확률이 매우 높은 대학 (예: 2개)
  * 적정(Target): 현재 성적과 합격선이 일치하는 대학 (예: 2개)
  * 소신/상향(Reach): 도전 목표 대학 (예: 2개)
- **전형 유형 선택**:
  * 학생부교과 전형 (내신 정량 + 수능최저 중심)
  * 학생부종합 전형 (내신 + 세특 정성평가)
  * 논술 전형 (논술 점수 + 수능최저)

### 2.2 정시 3개 군(가/나/다군) 목표 관리
- **군별 1지망/2지망 설정**:
  * 가군: 1개 대학/학과 선택
  * 나군: 1개 대학/학과 선택
  * 다군: 1개 대학/학과 선택

### 2.3 대학/학과별 전형 메타데이터 매핑
1. **내신 반영 방식 (수시)**:
   * 반영 교과목 (예: 전교과 / 국·수·영·과 / 국·수·영·사 등)
   * 진로선택과목 성취도 환산 (상위 3과목 등)
   * 전년도/예상 5등급제 환산 합격 컷
2. **수능최저학력기준**:
   * 등급 합 기준 (예: "국, 수, 영, 사/과(1) 중 2개 영역 합 5등급 이내")
3. **정시 수능 영역별 반영 비율**:
   * 국어, 수학, 영어, 탐구(사/과), 한국사 반영 비중 및 가산점 (미적/기하/과탐 3%)
