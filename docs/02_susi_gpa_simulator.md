# [모듈 2] 수시 내신 관리 & 역산(Goal-Seek) 시뮬레이터

## 1. 개요
첫째(고2)와 둘째(고1) 모두 **2028+ 개편안(내신 5등급제 상대평가 + 통합수능)**이 전면 적용되는 세대입니다.  
이미 산출된 실제 1학기 성적을 바탕으로, **"남은 학기 동안 몇 등급을 받아야 목표 대학에 갈 수 있는가?"**를 자녀별 학년 상황에 맞게 역산(Goal-Seek)합니다.

---

## 2. 자녀별 학기 관리 현황

| 자녀 구분 | 현재 학년 | 대입 연도 | 이미 완료된 성적 (실제) | 역산 시뮬레이션 대상 학기 (가상) |
| :--- | :--- | :--- | :--- | :--- |
| **첫째** | **고2** | 2028학년도 | **1-1, 1-2, 2-1 (총 3개 학기 완료)** | **2-2, 3-1 (남은 2개 학기 역산 집중 ⭐)** |
| **둘째** | **고1** | 2029학년도 | **1-1 (1개 학기 완료)** | **1-2, 2-1, 2-2, 3-1 (남은 4개 학기 장기 로드맵 ⭐)** |

---

## 3. 5등급제 내신 계산 규칙

### 3.1 등급 및 성취도 체계 (고1, 고2 공통)
* **석차등급 (1~5등급)**:
  * 1등급: 상위 10%
  * 2등급: 상위 10% 초과 ~ 34% 이하 (누적 34%)
  * 3등급: 상위 34% 초과 ~ 66% 이하 (누적 66%)
  * 4등급: 상위 66% 초과 ~ 90% 이하 (누적 90%)
  * 5등급: 상위 90% 초과 ~ 100% 이하 (누적 100%)
* **과목별 단위수(이수단위)**: 가중 평균 공식 적용
  $$\text{환산 등급} = \frac{\sum (\text{과목별 단위수} \times \text{과목 석차등급})}{\sum \text{총 단위수}}$$

### 3.2 학년별/과목별 반영 비율 처리
* **대학별 반영 교과 필터링**:
  * 자연계열: 국어, 수학, 영어, 과학 교과목만 추출하여 산출
  * 인문계열: 국어, 수학, 영어, 사회 교과목만 추출하여 산출
  * 전교과: 모든 이수 과목 반영

### 3.3 기존 9등급제 입결 ➔ 2028 5등급제 환산 변환 엔진
과거(2025~2026학년도) 9등급제 기준 입시 결과 컷을 2028학년도 5등급제 목표치와 직접 비교할 수 있도록 **누적 백분위 기반 선형 보간(Piecewise Linear Interpolation)** 변환식을 적용합니다:

1. **9등급제 누적 백분위 경계값**:
   - 1.00등급: 상위 0% / 1.50등급: 누적 4% / 2.50등급: 누적 11% / 3.50등급: 누적 23% / 4.50등급: 누적 40% / 5.50등급: 누적 60% / 9.00등급: 100%
2. **5등급제 매핑 구간**:
   - 1.00등급: 상위 0% / 1.50등급: 누적 10% / 2.50등급: 누적 34% / 3.50등급: 누적 66% / 4.50등급: 누적 90% / 5.00등급: 100%
3. **핵심 환산 기준치**:
   - 기존 9등급제 **1.50등급 (상위 4%)** ➔ 5등급제 **1.20등급**
   - 기존 9등급제 **2.00등급 (상위 7.5%)** ➔ 5등급제 **1.38등급**
   - 기존 9등급제 **2.37등급 (상위 10%)** ➔ 5등급제 **1.50등급 (1등급 마지노선)**
   - 기존 9등급제 **2.70등급 (상위 13.4%)** ➔ 5등급제 **1.64등급**
   - 기존 9등급제 **3.00등급 (상위 17%)** ➔ 5등급제 **1.79등급**
   - 기존 9등급제 **3.50등급 (상위 23%)** ➔ 5등급제 **2.04등급**

## 4. 핵심 세부 기능

### 4.1 학기별 내신 성적 입력 테이블
* **첫째(고2) 화면**:
  * 1-1, 1-2, 2-1 ➔ 실제 확정 성적 입력 폼
  * 2-2, 3-1 ➔ 시뮬레이션 목표 성적 폼
* **둘째(고1) 화면**:
  * 1-1 ➔ 실제 확정 성적 입력 폼
  * 1-2, 2-1, 2-2, 3-1 ➔ 시뮬레이션 목표 성적 폼

### 4.2 목표 등급 역산(Goal-Seek) 시뮬레이터 ⭐
* **고2(첫째) 시나리오**:
  * 3개 학기 성적이 누적되어 있으므로, 남은 2개 학기(2-2, 3-1)의 등급에 따른 최종 내신 변동 폭을 정밀 계산.
  * 슬라이더를 통해 *"2-2학기에 수학 1등급을 지키면 최종 몇 등급인가?"* 실시간 검증.
* **고1(둘째) 시나리오**:
  * 1-1학기 성적을 바탕으로, 앞으로 남은 4개 학기의 상승 곡선(예: 1-1에 2.0등급 ➔ 이후 올 1등급 달성 시 최종 누적 등급) 시나리오 제시.

### 4.3 수능최저학력기준 진단기
* 목표 대학의 수능최저 조건과 최근 모의고사 성적을 비교하여 [충족 ✅ / 위험 ⚠️ / 미충족 ❌] 표시.
